# 金币与选中反馈素材

- `MoneyBag.png`：用户提供的空数字牌金币袋，保留原始透明通道。
- `References/MoneyNumeralsReference.png`：用户提供的 1250 数字风格参考。
- `SelectionBlade.png`：用户提供的单剑选中标记。
- `HandCursor.png`：用户提供的手形鼠标图案。
- `GoldDigits.svg` / `GoldDigits.png`：按参考风格重绘的原创 0–9 字形；金色渐变、浅色倒角和棕色立体描边。并未识别为某个现成字体。

数字图集分为十个横向单元，每格 384×512 像素；运行时逐位取样，可随金币数变化。所有界面纹理采用 UI 分组、无 Mip、无流送及保留透明通道的压缩设置。

重新生成数字（Windows PowerShell 5.1）：

```powershell
powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\Scripts\build_ui_digits.ps1
```

然后在 UE Python 命令环境中运行 `Scripts/build_ui_assets.py`，将四张 PNG 导入 `/Game/Voxel/UI/`。此目录已加入打包必包含资源。

金币袋在 1440×900 的界面基准下占 200×200，位于左下功能栏上方；数字按包括描边和投影的完整轮廓居中，整体高度最多 19 像素，字面约 16 像素，位数增加时自动适配牌框宽度。整体随窗口比例缩放。

宝剑标记保持剑尖向下，沿剑柄到剑尖的纵轴每两秒自转一圈；使用原图的正反面和有厚度的轮廓侧面进行三维投影，正面、窄侧面和背面依次可见，独立于战场流速。手形指针基准尺寸为 56×56，比前版增大 40%；按住鼠标左键或右键时平滑收缩至 90%，松开恢复，缩放过程中指尖点击位置保持不动。
